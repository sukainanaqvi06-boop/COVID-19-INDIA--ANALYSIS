# COVID-19 India Analysis

# Project Overview:
Analysis of COVID-19 pandemic trends in India, focusing on confirmed cases and mortality trends to identify the most impacted periods.

# Tools Used:
* Python: Data cleaning, handling missing values, and preprocessing.
* MySQL: SQL queries for monthly trend analysis and identifying peak death rates.
* Power BI: Interactive dashboard visualizing total cases, deaths, and monthly growth.

# Key Findings:
* Peak Analysis: Identified the specific months with the highest death rates and case surges.
* Fatality Trends: Analyzed total deaths and their ratio relative to confirmed cases.
* Timeline Visualization: Tracking the pandemic's progress through interactive time-series charts.

# Files in Repository:
* covid_analysis.py (Cleaning Code)
* covid_project_queries.sql (SQL Code)
* Covid project.pbix (Power BI Dashboard)
